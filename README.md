# City_tour · ШКОАЛА

Интерактивная игра для уроков английского языка. 3D-город, мистер Коул, сообщения на телефоне и маршруты относительно персонажа.

## Быстрый запуск

- Для урока откройте `City_tour.html` из комплекта. Интернет для игры не требуется; доступность голоса зависит от голосов браузера.
- Файлы репозитория уже готовы для GitHub Pages: источник — ветка `main`, папка `/ (root)`. `index.html` находится в корне.
- Для локальной разработки используйте любой статический HTTP-сервер из корня репозитория.

## Режимы

**Missions.** Откройте сообщение и нажмите **On my way!**. Догадайтесь, куда нужно идти, доведите Коула до входа и отправьте **I’m here!**. Неудачная попытка даёт подсказку без раскрытия ответа. Двенадцать встроенных поручений охватывают все места, кроме исходной остановки.

**Follow directions.** Откройте маршрут от Alex и нажмите **Let’s go!**. Следуйте английским инструкциям и впишите место встречи. Проверяются название, фактическое положение и полный путь. Можно вернуться по своим следам после ошибки или перезапустить маршрут. В каждом сгенерированном маршруте есть **go past**. Генерация учитывает текущую точку и направление взгляда.

**Free walk.** Выберите стрелки или ходьбу по клику. Для клика нажмите на тротуар около нужного входа. Коул выбирает безопасный путь к ближайшему входу или углу. Подсказки для устной практики меняются кнопкой ↻.

## Управление

| Действие | Клавиша |
| --- | --- |
| Идти вперёд по тротуару | ↑ |
| Повернуться налево относительно Коула | ← |
| Повернуться направо относительно Коула | → |
| Развернуться | ↓ |
| Свернуть кнопки | Esc |

Поворот меняет ракурс всего тела, но не перемещает Коула. Экранные команды открываются через **Walk controls**. После ходьбы они сворачиваются. **More** открывает разворот и контекстное **Go past…**. Эта команда ведёт мимо следующего здания и останавливает у следующего входа или угла. В режиме клика экранные стрелки скрыты. До принятия задания управление закрыто.

## Карта и движение

13 мест: hospital, park, school, theatre, cinema, café, baker’s, garage, police station, post office, library, greengrocer’s, bus stop. Сохранена исходная 3D-карта целиком: здания, улицы, трамваи и расположение мест не перерисовывались. Маршруты проложены по её видимым тротуарам и существующим зебрам. Все места доступны. Здания стоят группами на одной территории, что позволяет тренировать **next to, between, opposite, in front of**.

Один шаг управления ведёт до входа или настоящего поворота на тротуаре. Промежуточные точки у бордюров не являются остановками. Переход у библиотеки проходится целиком до входа; ожидание зелёного начинается на тротуаре. Команда Go past также может проходить через переход со всеми проверками светофора.

Физика ходьбы и отрисовка используют одни координаты. Произвольные клики не телепортируют персонажа и не позволяют пройти через здание. Коул пересекает проезжую часть только по зебре. У края он ждёт пешеходный зелёный; красный для машин удерживается до завершения перехода.

У каждой зебры свой цикл: зелёный машинам → жёлтый → освобождение перехода → зелёный пешеходу → пауза перед возобновлением движения. Машина, пересёкшая стоп-линию до смены сигнала, заканчивает проезд. Следующие машины тормозят и держат дистанцию. Скрытая вкладка, пауза и открытые настройки замораживают симуляцию. Нет независимой CSS-анимации машин или сигналов.

## Панель учителя

Кнопка **⚙** открывает Teacher studio:

- названия мест и схема пешеходных путей;
- озвучка английских сообщений;
- включение и отключение движущихся машин;
- возврат на остановку и новый урок;
- собственные сообщения, удаление, импорт и экспорт JSON;
- русская инструкция.

Настройки, завершённые поручения и собственные сообщения сохраняются на текущем устройстве в браузере. Экспортируйте свои сообщения, чтобы перенести их на другой компьютер. В приватном режиме или при запрете локального хранения игра работает, но сохранение может быть недоступно.

Импорт поддерживает старый массив сообщений и формат версии 2:

```json
{
  "format": "city-messages",
  "version": 2,
  "messages": [
    {"sender":"Mum","text":"Please buy some bread.","target":"bakery"}
  ]
}
```

Допустимые `target`: hospital, park, school, theatre, cinema, cafe, bakery, garage, police, post, library, greengrocer. Максимум 100 своих сообщений, 40 символов в имени и 500 в сообщении. Некорректный импорт не заменяет существующие данные. Текст сообщений отображается как текст и не исполняет HTML.

## Исходники

| Файл | Назначение |
| --- | --- |
| `world.js` | Места, пешеходный граф, поручения и генерация маршрутов |
| `traffic.js` | Светофоры, торможение и пешеходные блокировки |
| `walker.js` | Движение по разрешённым сегментам |
| `draw.js` | Карта, здания, автомобили и сигналы |
| `app.js` | Интерфейс, режимы, проверка ответов, настройки |
| `style.css` | Оформление, адаптация и анимации |
| `tests.cjs` | Проверки графа и симуляции без браузера |

Команда `node tests.cjs` из корня репозитория проверяет доступность мест, отсутствие диагональных срезов, существующие переходы, остановку на красный, безопасность пешехода, дистанцию между машинами, сброс занятого перехода, режим без трафика, генерацию маршрутов и варианты ответов. Проверки используют те же модули, что игра.

В игре нет сторонних JavaScript-библиотек, внешних шрифтов, аналитики или сетевых запросов. Изображения Коула и зданий перенесены из предыдущей версии пользователя. Доступ к размещённой на GitHub Pages игре определяется настройками хостинга: встроенной системы покупок, паролей и лицензирования в этой сборке нет.
